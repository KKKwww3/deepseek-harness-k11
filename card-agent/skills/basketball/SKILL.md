# 篮球球星卡识别

## 关注字段

1. **球员（name）**：卡面最显著的人名，通常是头号明星。格式「名字 姓」。
2. **系列（set）**：如 Prizm、Select、Donruss、Panini、Topps Chrome 等。通常在卡面角落或底部。
3. **年份（year）**：系列年份，如 2020-21。
4. **卡号（number）**：编号 + 总数，如 `220/300`；或纯序号。可能在正面角落或背面。
5. **平行/折射（conditionNote 可记录）**：同一球员不同底色/折射（如 Green、Silver、Red Parallel）。折射颜色通常能凭底色判断，但**不确定时不猜测**，留空即可。
6. **成色（conditionNote）**：仅当明显可见时记录，如「角损」「划痕」；看不清则不写。

## 规则

- 卡号只取可见的编号，格式保持原样（`220/300`）。
- 读不清的字段置 `null`，绝不编造。
- 篮球卡正面常有竖版人像 + 球队名 + 系列名；背面为球员数据表格。
- 若整张卡模糊、反光严重导致信息不可读，标 `confidence: low` + `needsReview: true`。
