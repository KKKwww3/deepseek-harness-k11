# 篮球球星卡识别

NBA 球星卡以 Panini、Topps 等为主，按以下要点提取。

## 正面卡面布局

- **球员名（Player name）**：正面最显著位置（通常竖排或横排大号字体）。
- **球队**：球员名附近或球衣上的球队名/队标。
- **年份与系列**：通常位于顶部或底部小字，例如 `2020-21 Panini Prizm`、`1998-99 Topps Chrome`。
- **卡号（Card number）**：卡片底部，格式如 `220/300`、`#105`。
- **位置**：正面或背面标注的 SG/PG/SF/PF/C。
- **新秀卡（RC）**：若为 rookie card，通常在正面有 `RC` 标记，务必记录。

## 识别优先级

1. 球员名 + 年份 + 系列（决定卡的身份）。
2. 卡号。
3. 球队/位置/是否新秀作为补充。

## 常见陷阱

- 年份是赛季区间（如 `2020-21`），不要只取一个年份，保留区间。
- 同一年份+系列可能有平行卡（不同颜色背景/编号），若可见则记录。
- 编号 `XX/XXX` 中的 `XXX` 是限量总数，保留完整格式。
- 签名卡/球衣卡若可见，在 `conditionNote` 或 `notes` 中标注。

## 输出示例

- name: "LeBron James", set: "Prizm", year: "2020-21", number: "220/300"
- name: "Stephen Curry", set: "Topps Chrome", year: "2009-10", number: "111/220"
