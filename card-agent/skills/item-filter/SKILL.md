# 图内过滤与角色判定

当面对客户提供的图片时，先判断每张图片的角色，只对真正需要识别的图进行提取。

## 角色枚举

| 角色 | 含义 | 出现在 |
|---|---|---|
| `front` | 单张卡片的正面 | 单卡（singles） |
| `back` | 单张卡片的背面 | 单卡（singles） |
| `core_front` | lot 中核心卖点卡片的正面 | lot |
| `core_back` | lot 中核心卖点卡片的背面 | lot |
| `group` | lot 的整组卡片正面合照 | lot |
| `label` | lot 的标号 + 透明包装袋图片（含编号信息） | lot |
| `unrelated` | 标签、文字描述、包装特写、其他杂物 | 任何位置 |

## 识别要点

- **正面（front/core_front）**：卡面主体是卡片图案，通常能看到卡名/球员、系列名、编号。
- **背面（back/core_back）**：通常是说明文字、规则、条码、版权信息，没有卡面主图。
- **整组合照（group）**：一张图上有多张卡并列（约 10 张），用于确认总卡数。
- **标号/包装图（label）**：图上有手写或打印的编号（如 LOT-202）、透明包装袋，可能含价格/文字标签。
- **干扰图（unrelated）**：不是卡片本身——例如纯文字说明、店铺标签、发票、包装盒外观等。这类图**不要识别，直接跳过**。

## 判定后处理

- 角色为 `unrelated` 的图：**不提取任何卡片信息**，仅在记录中标记为跳过。
- 一个单卡通常 = 1 张 `front` + 1 张 `back`。
- 一个 lot 通常 = 1 张 `group` + 1 张 `label` + 若干 `core_front`/`core_back`。
- 若同一组内有多张图属于同一角色（例如 2 张 core_front），分别记录，不合并丢弃。

## 输出约束

不要把 `unrelated` 图的信息写入卡片识别结果。`label` 图只用于提取 lot 编号和确认包装信息，不提取卡名。
