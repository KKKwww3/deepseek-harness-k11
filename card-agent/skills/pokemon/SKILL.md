# 宝可梦卡识别

宝可梦 TCG 卡面信息分布相对固定，按以下要点提取。

## 正面卡面布局（常见位置）

- **卡名（Pokemon name）**：卡面顶部，通常在一行彩色标题栏内。
- **HP 与属性**：卡名右侧有 HP 数值与属性符号（火/水/草/电等）。
- **卡号（Card number）**：卡片底部（或右下角），格式通常为 `XX/XXX`，例如 `025/165`；部分特殊卡为 `XXX/XXX` 或 `XX/XXX+`。
- **系列名（Set / expansion）**：卡片底部或侧面小字，例如 `151`、`Scarlet & Violet`、`Crown Zenith`。
- **稀有度标记**：卡面右下角附近的图标/字符（如 R、RR、Holofoil 反光效果等）；反光/全息可标注进备注。
- **年份**：卡片版权行（`©2023` 等）底部小字，或在系列发行年代推断。

## 识别优先级

1. 先读卡号与系列名（决定"这是哪一张"）。
2. 再读卡名。
3. 稀有度与全息效果作为补充信息，放入 `conditionNote` 或 `notes`。

## 常见陷阱

- 卡号是 `XX/XXX` 时，`XX` 是卡号、`XXX` 是系列总卡数，两者都要保留。
- 同一宝可梦可能有多张（不同系列/不同编号），以卡号和系列区分，不要合并。
- 若卡面是训练家卡、能量卡，按实际类型标注，不要臆测为宝可梦本体。

## 输出示例（name/number/set 三个字段必须给）

- name: "Charizard", set: "151", year: 2023, number: "006/165"
- name: "Pikachu", set: "Crown Zenith", year: 2023, number: "160/159"
